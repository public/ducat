# Equivalent mutants

The nightly mutation run (see [How ducat is tested](how-ducat-is-tested.md#mutation-testing)) leaves some mutants alive that no test can kill, because no input can tell them from the original code. Where every mutant of one kind on a line is like that, a `// Stryker disable next-line` comment at the site says why. This page lists the rest, file by file: mutants on lines where the tests kill other mutants of the same kind, so they show as "survived" in the report.

## rounding.ts

| where                                                                         | mutants                                                                | why they are equivalent                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `divideAndRound`, the bigint fallback for `\|dividend\| + divisor > 2^53 - 1` | every mutant of the guard                                              | The float path is exact for every safe dividend and divisor, so taking the bigint path more or less often gives the same quotient (the argument is in the next row).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `divideAndRound`, the correction of the float quotient                        | the four branches emptied or negated, `dividend >= 0` as `> 0`         | The float quotient never needs correcting. For a dividend a >= 0 and divisor b >= 1, both safe, let k = floor(a/b). k is an integer below 2^53, so it is a double, and rounding is monotone, so `Math.trunc(a / b)` is at least k. It would be k + 1 only if a/b rounded up to k + 1. With P = (k + 1)·b, that needs P − a ≤ P·2^−53 (half the spacing of doubles below k + 1, times b), and with a ≤ 2^53 − 1 that gives P ≤ 2^53. But a < P makes P − a ≥ 1, so P ≥ 2^53, and P = 2^53. Then k + 1 and b are powers of two, and the gap 1/b is more than half the spacing below a power of two, so a/b doesn't round up. So the quotient is exact; q·b ≤ a is exact, and so is the remainder. Negative dividends are the mirror image. `test/rounding-edges.test.ts` checks the top of the range against the proved kernel in every mode. |
| `divideAndRound`, `divideAndRoundBigint`                                      | the `divisor === 1` shortcuts as `false`; `remainder === 0` as `false` | The general path gives the same quotient.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `divideSafeByRatio`                                                           | `numerator < 0` as `<= 0`                                              | A zero divisor is rejected before this is called.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
