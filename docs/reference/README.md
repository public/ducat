# Reference

Every entry of `@ducatjs/money`, with what importing it installs on `Money` and what it exports. Each page lists every function, method, type and constant of its entries, with its signature, how it rounds and what it throws.

The pages mirror the package: one per entry, or one for a family of entries (the six processors, the rate sources, the Drizzle dialects, the currency data entries). `/fn` and `/all` re-export the other entries, so their pages list entries rather than names.
